# 交接說明

給在別的視窗（桌面版 Claude Code、或新開的對話）接手這個專案的人／模型看的。
一頁講完現況，不用回頭翻對話。

## 這是什麼

新北市稅捐處三峽分處的工具：把掃描的紙本申請書 PDF 轉成兩個檔，
一個給外網 RPA 查謄本，一個給內網腳本查戶籍。全程離線，不連網路。

- 使用者是承辦人，不是工程師。全程用繁體中文溝通。
- 三個欄位必須正確：**門牌、身分證字號、公文文號**。姓名只供人眼核對。
- 輸出規格見 `docs/output-spec.md`，表格的眉角見 `docs/form-notes.md`。

## 目前唯一卡住的問題

內網中繼檔（`輸出\HH<民國日期>_01.xlsx`）的「完整地址」欄
**要不要含縣市與行政區**。

現在產的是含的：`新北市三峽區中正路二段15號`。
依據是內網腳本 0 的 `district = Mid(address, 4, 3)`（從第 4~6 個字取行政區，
反推第 1~3 個字是縣市）。

真正拆欄位的是 `Hro_ExportCurrent`，它在
`\\10.46.110.253\驅動程式區\RPA_Shared\CommonExcelLib.vbs` 裡。
**那個檔在內網，使用者取不出來，不要再要求他提供。**

### 怎麼確認

叫使用者實測，不要靠讀原始碼推論：

1. 用程式產一個檔（假資料兩三筆）
2. 放進內網的 `地價稅通用腳本` 資料夾，確認裡面沒有別的 xlsx
3. 跑腳本 2，模式選 1
4. 打開產出的 `上傳檔案\upload1.xls` 看 B、C、F 欄

B=`新北市`、C=`三峽區`、F=`中正路二段15號` 就是對的。
F 欄開頭被切掉，就改 `pipeline/output.py` 的 `inner_address()`，把
`INNER_CITY + district` 拿掉即可，一行。

## 已經確定的事（不要重新推翻）

從內網腳本 2 的原始碼直接讀出來的：

- 中繼檔**必須是 .xlsx**。它只找 xlsx，csv 與 xls 看不到
  （`If LCase(fso.GetExtensionName(objFile.Name)) = "xlsx"`）
- **要有標題列**，欄名一字不差。它用名稱取值不是位置
  （`District = firstRow.RawData("行政區")`）
- 多一個「姓名」欄不干擾它
- **那個資料夾裡只能有一個 xlsx**，撿到第一個就 `Exit Function`。
  外網那份清冊也是 xlsx，不能放一起

外網那條路已經全部確認完，不用再動。特別注意 xlsx 的 E~H 欄一定要留空，
備註欄有內容 RPA 會整列跳過而且不出聲。

## 使用者的環境與限制

- Windows 11 24H2，**沒有管理員權限**
- 每天 10~20 件，一批
- 外網用 Power Automate，內網用 UFT One（腳本是 VBScript）
- 內網的東西一律取不出來。他也不會為了這個專案去繞過資安控管，不要建議他這麼做

## 隱私（重要）

**絕對不要叫他上傳真實的申請書。** 姓名＋身分證＋門牌＋地號送到境外
AI 服務，很可能違反個資法與機關資安規定。這一點從一開始就跟他講清楚了。
要測準確率就用診斷報告（見下）。

## 診斷報告

程式裡有一套診斷機制（`pipeline/diagnose.py`），複核畫面按「產生診斷報告」
會產出一份**遮罩過、不含個資**的純文字檔，可以外傳。
中文字→字、數字→9、英文→A，只留路街段巷弄號樓等結構字。

有問題就叫他產一份貼過來，不要叫他截圖或形容。
