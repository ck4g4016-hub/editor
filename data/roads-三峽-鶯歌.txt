# 三峽區與鶯歌區的路街名字典。
#
# 來源：內政部「村里街路門牌服務」開放資料 opendata115road.csv（民國 115 年版），
#       由承辦人提供，本檔取 city=新北市 且 site_id 結尾為三峽區／鶯歌區者。
#       114 年版與 115 年版在這兩區完全相同，已比對過。
#
# 這份**是**官方門牌資料，跟先前那份從郵遞區號網站抄來的種子清單不一樣。
# 先前那份漏了鶯歌區的「大湖路」，害門牌被吸附到「東湖路」——
# 那是另一條真的存在的路，驗證還會通過，從輸出表上完全看不出來。
#
# 「## 區名」以下的路名屬於該區。分區是必要的：
# 三峽有「仁愛街」、鶯歌有「仁愛路」，合在一起就分不出該用哪一個。
#
# 表格上的「路」「街」是印刷的、民眾只是圈起來，讀出來不可信，所以比對只看
# 主體（「大湖」對「東湖」），由字典決定是路還是街。這兩區裡只有一組主體
# 同時有路也有街 —— 鶯歌的「東湖街」與「東湖路」—— 那一組程式分不出來，
# 會標起來讓人看，不會替你猜。
#
# 注意有幾個沒有路街結尾的（三峽的白雞、插角、有木、金敏、五寮、建安、添福，
# 鶯歌的三界公坑、圳頭坑），那些是以地名編門牌的地區，官方清單就是這樣收的。
