# 機關代號 —— 公文文號中間那三碼。**這份設定是選用的，多數情況用不到。**
#
# 公文文號的組成：
#
#     115      民國年
#     569      機關代號
#     XXXX     流水編號
#
# 程式是這樣找的（逐層縮小，剩下剛好一個就用它）：
#
#     1. 整頁上十碼、開頭三碼是合理民國年的數字
#     2. 還不只一個 → 留下年份跟這一頁收文日期同年的
#     3. 還不只一個 → 留下中間三碼符合這份設定的
#     4. 還是不只一個 → 標記起來，不猜
#
# 實測承辦人給的四件，第 1 層就只剩一個候選 —— 完全沒用到這份設定。
# 所以機關代號跳號（5670001 用完換 5680001）或跨年度換一組，
# **程式不必改，這個檔也不必動**。
#
# 只有在同一頁上出現兩個以上都像公文文號的十碼數字時，這份設定才派上用場。
# 那時候可以填單一個值，或填一段範圍（代號會隨流水號用完往上跳）：
#
#     569         單一個
#     567-575     一段範圍
#
567-575
